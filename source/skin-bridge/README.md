# LARP Launcher Skin Bridge

Pins LARP Client 2.2.6 and Minecraft 1.21.11. Uses the existing SkinChanger public API and Fabric client lifecycle/network events. Reads game/config/larp-client/launcher-skin.json written by the launcher; the local PNG is game/config/larp-client/skins/launcher.png.

Local choices are applied once per preferences revision after the existing module has initialized and enumerated skin files. User profiles are not rewritten by the bridge.

Server sync is opt-in. It waits up to 120 seconds after joining for the server to advertise skin in its command tree, then sends one validated name/URL request. Server permissions and acceptance are still required. It never changes authentication or uploads PNGs. Live multiplayer behavior has not been tested.

Build: powershell -NoProfile -ExecutionPolicy Bypass -File .\\source\\skin-bridge\\build.ps1

Requires an intermediary client JAR generated by a previous Fabric game start, or explicit -MinecraftJar. Uses the bundled Java 21 tools and nested Fabric API dependencies; executes the Java command validation tests before packaging.
