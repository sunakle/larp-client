LARP CLIENT — ПОЛНАЯ СБОРКА

Распакуйте всю папку и откройте LARP Client.exe.
Java 21, Minecraft 1.21.11, Fabric, библиотеки и моды включены.
Введите имя игрока, выберите память и нажмите ИГРАТЬ.

Используется локальный профиль без входа Microsoft.
Личные аккаунты, миры, серверы и журналы не включены.
Все инструкции: README.md.
